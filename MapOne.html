Yosemite National Park
Glacial Maximum

For this project I used a DEM of the area, and polygon feature class of the ice sheet extent, and an excel sheet of the ice depth point measurements. Using the DEM I created a shaded elevation relief map with contour lines. Using the polygon feature class I used the vertices to points tool to outline the polygon with points then added the elevation data to these points using the DEM. I then created a TIN of the ice surface which is then converted into a raster. I was then able to use the raster calculator tool to find the total thickness of the ice sheet at each point.
